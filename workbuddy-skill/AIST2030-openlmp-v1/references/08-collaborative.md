# 协作学习 · 执行手册（1 个方法）

> 详细步骤、验收线与 Agent 契约。每个方法的 checkpoint 都是**可判定**的，无法判定就说明这一步没做扎实，不要靠感觉通过。

### 1. 结对学习（`pair-learning`）

*Pair Learning*

**两个人学同一件事，每周交换一次「出题人」和「答题人」角色。强迫你换视角——讲解别人的卡点，比自己学更快暴露盲区。**

- **分类**：协作学习
- **循证等级**：medium —— 有一些支持性证据，但结论稳健性中等
- **版本**：0.1.0　**许可**：CC0-1.0

**适用场景**

- ✓ 自学容易走偏没人纠
- ✓ 想快速上手新技能
- ✓ 备考互相出题

**不适用**

- ✗ 找不到合适的人
- ✗ 内容涉及必须独立完成的能力（如写作风格）

**入参**

- `partner`（**必填**，string）：搭档，需大致同水平
- `topic`（**必填**，string）：结对共同攻克的主题，需双方都具备基础才能讨论

**执行步骤**

1. **定好角色轮换**（`role-rotate`，约 5 分钟）
   - 做什么：约定每周轮换：A 讲解 B 提问，B 提问 A 讲解。**必须轮换**——单方面讲解的人成长最慢，因为他没被问到盲区。
   - 验收线：产出轮换表，且本次谁讲解谁提问已明确
   - 产出：rotation
2. **讲解人的 5 分钟**（`teach-back`，约 6 分钟）
   - 做什么：讲解人用5 分钟讲清本周学的核心，**不许念稿子**，不许看笔记。
   - 验收线：讲解全程不看材料；且包含至少一个具体例子
   - 产出：teach-back
3. **提问人只问「为什么」**（`questioner`，约 6 分钟）
   - 做什么：提问人**不许问「是什么」**（那是复述），只许问「为什么」「如果 X 变了会怎样」「你说的这个和 Y 矛盾吗」。每问一个就判断：答案里有没有逻辑跳跃？
   - 验收线：提问 ≥3 个且全部是「为什么/如果」类；至少找出 1 处逻辑跳跃或含糊处
   - 产出：questions + gaps
4. **讲解人当场补漏**（`explain-gap`，约 8 分钟）
   - 做什么：被问住的地方，当场去查，或明确说「这个我不知道，记下来」。**不许糊过去。**
   - 验收线：所有被问住的地方都有结论（查到或明确未知）；无糊弄
   - 产出：gap closure
5. **反向出题**（`swap-question`，约 12 分钟）
   - 做什么：由提问人出 3 道题给讲解人做。**做不出来正是本环节的目的**——不是测验，是找盲区。
   - 验收线：出题 3 道且难度对等；做错/做不出处已记录进错题本
   - 产出：test
6. **记录不对称**（`symmetry-check`，约 5 分钟）
   - 做什么：记录：谁被问住得更少？连续两周都是同一个人，说明另一个人提问不够狠，需要换策略（改成互相出题）。
   - 验收线：给出了「谁被问住更多」的事实判断，并据此决定是否调整方式
   - 产出：symmetry note

**Agent 契约**

- 输入：partner, topic
- 输出：questions + gaps
- 降级：无搭档时：Agent 扮演提问人，且**必须真的问出尖锐问题**，不许敷衍地说「很好，继续」。扮演讲解人时 Agent **不得**代替用户作答

**自检问题**

- 这周我是讲解多还是提问多？我是不是一直只做擅长的那个？
- 搭档指出的问题，是我没意识到的还是不想承认的？

**达标判据**

- 双方被问住的次数差距 <2倍
- 每次都能说出至少 1 个自己没意识到的盲区

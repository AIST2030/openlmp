# 方法宇宙索引（METHOD-UNIVERSE）

> 本文件是 OpenLMP 的"总清单对照表"。我们把一份约 300 种、跨九大领域的方法总谱摊开，
> 逐域标注它和 OpenLMP 可执行 Skill 库的关系。目的：让"全维度铺开"有据可查，
> 既说明为什么只有一部分做成了可执行 Skill，也为后续扩充留下候选队列。

## 收录标准：什么才能成为 OpenLMP 的可执行 Skill

OpenLMP 的核心承诺是**每个步骤都有机器可判定的验收线**（checkpoint）。因此一个方法要成为
可执行 Skill，必须同时满足：

1. **过程可拆步**：能写成 ≥2 个有序步骤，每步有明确动作。
2. **验收可数**：每步能给出"做到了/没做到"的客观判据，而非"感觉懂了"。
3. **纯度过关**：不涉及注册登录、API 密钥、上传云端、订阅付费、站外引流。
4. **不依赖不可验证的前提**：不说"气感对了""悟了"，而是说"写出了 X、答对了 Y"。

**结论**：学习方法、思维方法、分析方法大多可做成可执行 Skill；而**国学修行、冥想调息、
临床心理疗法、商业战略框架**大量依赖主观体验或需要专业资质/语境，无法满足第 2、4 条，
因此**只作参考索引，不硬塞成假 Skill**——这正是为了保护"可判定"这块招牌不被稀释。

状态图例：✅ 已收录为可执行 Skill · 🔵 候选（可做成 Skill，待排期） · ⚪ 仅参考（不做可执行）

## 扩充优先级建议

若要继续把 OpenLMP 从 70 往上推，按"可判定性强 × 通用性高"排序，建议下一批优先做：

1. **5Why、5W1H、鱼骨图、帕累托分析**（分析基本功，验收线清晰）
2. **微习惯、精力管理、晨间/晚间复盘**（自我管理高频场景）
3. **SQ4R、睡前醒后记忆、谐音联想、白纸默写**（学习方法补全）
4. **SWOT、PDCA、决策矩阵**（若允许适度贴近"通用问题解决"定位）

商业框架、国学修行、冥想、心理疗法四大域**维持参考索引**，不进可执行库——这是 OpenLMP
保持"每条都能过验收线"这条招牌的边界，也是它和普通"方法大全"的区别。

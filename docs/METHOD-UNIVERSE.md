# 方法宇宙索引 · 分流结果（METHOD-UNIVERSE）

> 本文记录那份约 300 种、跨九域的方法总谱，在 OpenLMP 里的最终分流结果。
> 原则只有一条：**能做成"每步有机器可判定验收线"的才进库；不能的，按理念砍掉或另立子库，不硬塞成假 Skill。**

## 一句话结论

约 300 种总谱 → **主库收录 107**（含本次从候选中落地 29 个）+ **商业子库 15** + **砍掉约 130 个不可判定的**（国学修行/冥想/临床疗法/纯觉悟取向）+ 少量留作远期候选。

---

## 一、进主库的（学习方法 + 思维方法 + 分析方法）

本次从🔵候选中落地 **29 个**，主库从 78 → 107，并新增两个分类「思维方法」「分析方法」：

| 分类 | 本次新增 |
|---|---|
| 知识管理 | `sq4r` SQ4R、`two-column-notes` 二等分笔记、`qa-notes` 一问一答笔记 |
| 记忆巩固 | `tree-memory` 树状图记忆、`emotion-anchoring` 情绪联动、`backstitch-review` 回针缝复习 |
| 评测验证 | `pen-not-erasable` 圆珠笔法、`write-to-recall` 书写记忆检查 |
| 计划执行 | `gantt-progress` 甘特进度、`habit-consistency` 习惯性学习、`goal-backward` 目标逆向 |
| 元认知 | `effort-outcome-matrix` 努力分解矩阵 |
| 理解构建 | `spiral-learning` 螺旋学习 |
| **思维方法**（新分类） | `five-whys`、`five-w1h`、`mece`、`logic-tree`、`six-hats`、`scamper`、`lateral-listing` |
| **分析方法**（新分类） | `pareto`、`fishbone`、`decision-matrix`、`pdca`、`ooda`、`gap-analysis`、`hypothesis-method`、`elimination`、`reductio` |

（上一轮已落地的 `sleep-wake-memory`、`mnemonic-association`、`blank-sheet-daily` 亦属此类。）

---

## 二、进商业子库的（business/）

商业/管理/营销/战略/表达框架，**不进主库、单独成子库**（同协议、独立成库，见 [`business/README.md`](../business/README.md)）。第一批 15 个：

商业分析：`swot`、`pestel`、`porter-five-forces`、`bcg-matrix`、`ansoff`、`value-chain`、`business-model-canvas`
商业战略：`positioning`、`second-curve`、`flywheel`
商业管理：`okr`、`kpi`、`balanced-scorecard`
商业表达：`pyramid-principle`、`prep`

> 后续批次候选：3C、GE 九格、蓝海 ERRC、VRIO、精益画布、STP、4P/4C/4R/7P、产品生命周期、品牌资产、颠覆性创新、长尾、三层面、经验曲线、MBO、EVA、SCQA 等——都在商业子库排队，不占主库。

---

## 三、按理念砍掉的（不做成 Skill，也不进子库）

以下域**通不过"机器可判定验收线"**，硬做只会稀释 OpenLMP 的招牌，故明确砍掉：

| 域 | 规模 | 砍掉理由 |
|---|---|---|
| 国学·儒释道修行体系 | ~45 | 验收是内在体验（气感/悟/心安），无法客观数判定，且涉身心安全与专业语境 |
| 冥想与身心修炼 | ~30 | 同上；部分涉健康安全，不做成可判定 Skill |
| 心理学·临床疗法 | ~35 | CBT/MBSR/ACT/DBT/IFS/EFT/图式/叙事/SFBT 等需专业资质与临床语境，OpenLMP 不涉足 |
| 西方哲学修养（除苏格拉底诘问） | ~18 | 多为修养取向与世界观，验收线弱；唯 `socratic` 因可拆成可判定追问步骤而已收录 |
| 纯觉悟/取向类 | 若干 | 破我执、臣服接纳、宽恕练习、系统思维、水平/垂直思考、奥卡姆剃刀、发散/收敛等——是原则或取向，不是可逐步验收的操作 |

> 这些不是"没用"，而是"不属于 OpenLMP 这种可判定协议"。它们可作为文化参考另存，但不进 `skills/`、不进验收体系。

---

## 四、远期候选（可做、待排期）

学习方法里与已收录高度重叠、需先做出增量差异化的：
`SQ4R` 变体、`树状图`/`思维导图`/`概念图` 的进一步区隔、`一问一答`/`迁移提问` 深化、`白纸默写`/`合书写作`/`书写检查` 的场景细分、`快速循环`/`三遍阅读` 深化。

原则：**不重复造轮子**——新增必须说清与现有 Skill 的差异，否则宁可不加。

---

## 五、这次确立的两条边界

1. **主库 = 学习方法 + 思维方法 + 分析方法**（帮人"学得会、想得清、做得对"）。
2. **商业框架 → 商业子库；不可判定的修行/疗法/觉悟 → 砍掉。**

这两条边界，是 OpenLMP 区别于普通"方法大全"的根本：**每条都能过验收线。**

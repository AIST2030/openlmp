# OpenLMP 目标对齐书 v1.0

> 用途：把「文心版」和「协议版」两份材料，压缩成一张可决策的对账表。
> 结论先给：**这两份材料是两个不同的产品，必须二选一，不能并行。**

日期：2026-10-21 · AIST2030

---

## 一、先说最重要的发现：文心版撞红线了

我查了现行监管，**文心版最核心的卖点在中国是死路**：

### 1. K12 学科学习 Skill —— 直接撞「双减」

> 原文：**「不再审批新的面向学龄前儿童、义务教育阶段、普通高中学生的学科类校外培训机构**」
> —— 《校外培训机构行业"一业一册"合规经营指南》，2026-05-29

2026 年多地已**全面清零**：泸西县「学科类校外培训机构已全面关停……完成清零」；临海市「没有教育部门许可的面向中小学生和学龄前儿童开展线下学科类培训的机构」。

**红线上还写明了要防的伪装形式**：
> 「严禁以托管、教育咨询、家庭教育指导、文化传媒……名义**变相开展学科类培训**」

⚠️ 这意味着：**「AI 自学工具面向中小学生 + 强调提分/同步课标」这个组合，即使不收一分钱，也可能被认定为变相学科培训。** 哪怕叫「AI 自习室」也一样（临海通报里点名了）。

### 2. 「全年龄段」是最危险的一个词

- **K12 学科** → 双减雷区
- **未成年人** → 《生成式AI办法》第十条明确要求「防范未成年人用户过度依赖或者沉迷」
- **儿童数据** → 个保法 + 未成年人保护法双重要求

### 3. 「100% 杜绝 AI 幻觉、所有输出溯源」——做不到，且是虚假宣传

技术上不存在 100%。这句话写进任何对外材料 = **广告法风险 + 虚假宣传风险**。
（这条跟你官网禁「免费」、禁绝对化用词是同一类红线。）

### 4. 收益分成 / 积分换分红 —— 你已经在另一个项目里否掉了

这条极其重要：**你在拼豆小程序项目里已经明令「用个人主体，绝不用企业主体」**，理由就是「企业流量主收益提现难 + 用户无对公账户」。

同一个道理在这里：**「自动给全球贡献者发收益分成」需要跨境结算主体、需要税务、需要支付牌照。** 一旦要发钱，就必须有公司、有财务、有对公账户 —— 也就是**必须有中心**，而且是重中心。这跟你「去中心化」的目标直接矛盾。

## 二、两份材料的本质对账

| 维度 | 文心版（AI 教育智能体） | 协议版（OpenLMP v0.1） |
|---|---|---|
| 本质 | 一个**产品**（要服务器、要模型、要算力） | 一份**协议**（纯文件，零依赖） |
| 交付物 | AI 教育 App / 智能体 | JSON 规范 + Skill 库 |
| 是否需要主体 | **需要**（备案、许可证、结算） | **不需要** |
| 是否收用户数据 | **必须收**（学情画像、记忆库） | **协议禁止收** |
| 你的角色 | 运营者（天天被投诉/被下线风险） | 发起人（发完就不管） |
| K12 学科 | ❌ 双减直接封死 | ✅ 不碰学科培训，只碰学习方法 |
| 收入 | 可能（但需主体+许可） | 无（且**这是设计意图**） |
| 99% 失败方式 | 做完没人用，或用完被关停 | 没人用，但**不消耗你** |
| 一个人能做完吗 | ❌ 不能 | ✅ 已做完 v0.1 |

**一句话结论：**
> 文心版是「**我要造一个平台并运营它**」；协议版是「**我发布一份规格，然后它不需要我**」。
> 后者才是你说的「我的能力太小，如何让全人类和 AI 自动参与」——**因为它不需要我参与**。

## 三、真正的对账：你的核心诉求 vs 两版答案

你说「**我的能力太小，如何让全人类、甚至 AI 自动来参与这件事**」。

这句话本身就是答案。我把它拆开看：

| 你的诉求 | 文心版给的答案 | 我判断 |
|---|---|---|
| 我能力不够 | 借 AtomGit 160万开发者流量 | ❌ 借来的流量会还 |
| 让人自动参与 | 收益分成 + 积分激励 | ❌ 需要中心主体，且你是个人主体（你自己刚否过） |
| 让 AI 自动参与 | AI 集群自动爬教材生成 Skill | ⚠️ 有价值，但**有幻觉风险和合规成本**，且需备案 |
| 项目不需要我 | 「你只需作为初始发起者高维见证」 | ❌ 自欺：产品一旦有人用，就需要维护者 |

**但有一个东西确实能解决「不需要我」——而且它是文心版里最值钱的一格：**

> **「把方法拆成 Skill，让任何 AI 直接读取并执行」**

这一格才是无中心的。它不需要服务器、不需要你运营、不需要主体。
它是**唯一能同时满足「AI 参与」「人类参与」「零门槛」「我不能做中心」的格子**。

其他所有格子（感知层/决策层/记忆库/多模态/学情画像/知识图谱/RAG/自动审核）**全都要服务器 + 数据 + 主体 + 备案**，一个都绕不开。

## 四、目标定义（请你先拍这个）

我建议把目标收敛成一句话，其余全部降级为可选：

### 主目标（唯一）

> **让任何人，把「想学 X」变成「一份可执行的学习方案」，零注册、零成本、数据不出本地。**

这句话里每个词都是可验收的：
- 「任何人」→ 不需要账号、不需要付费
- 「想学 X」→ 场景自由（背单词/学钢琴/考公/学编程/改写作）
- 「可执行的学习方案」→ 不是「建议你要坚持」这种废话，而是**带时间、带 checkpoint、带完成判据的步骤**
- 「数据不出本地」→ 这是 OpenLMP 唯一的硬承诺，也是最难被复制的护城河

### 明确放弃的主目标（这才是重点）

| 放弃项 | 理由 |
|---|---|
| ❌ K12 学科同步/提分 | 双减直接封死，伪装形式也封死 |
| ❌ 采集学情数据 | 采集即主体责任 + 备案 + 未成年人风险 |
| ❌ 收益分成 / 积分变现 | 需要中心主体，与去中心化矛盾；且你个人主体做不了 |
| ❌ 全年龄段覆盖 | 3 岁幼儿到退休 = 一个不可能验收的范围 |
| ❌ 100% 杜绝幻觉 | 做不到，写出来就是虚假宣传 |
| ❌ 「不需要我维护」 | 只有纯文件协议能做到，产品做不到 |

**放弃这些，不是因为不重要，是因为它们每一个都要「中心」，而中心就是你能力不足的那个东西。**

## 五、方式：三层里只做一层

```
第三层  全场景智能体（学情画像 / 记忆库 / RAG / 多模态 / 知识图谱 / 自动审核）
         ↑ ❌ 全部要服务器 + 数据 + 备案 + 主体 —— 一个人做不了，碰 K12 就违法
         ↑ 🔵 未来若有人做，作为「可选商业层」存在，不是我们的责任

第二层  学习 Agent 编排（读 Skill → 生成方案 → 交付成果）
         ↑ 🔵 **这一层是空的，等别人来填，或用 WorkBuddy 直接填**

第一层  Skill 契约 + 方法库   ✅ 已完成 v0.1，可运行，实测通过
         ↑ 纯 JSON，任何 AI 可读，任何人可改，不依赖我们
```

**关键判断：第一层做扎实，第二层自然长出来，第三层永远不要自己扛。**

你原本的设计试图一次性做完三层。那是「一个人造 AGI」的路径。
现在改成：**只做第一层，别人做完二三层，一层就是地基。**

## 六、成本（真实数字，含你的既有资源抵扣）

### 阶段一：把方法库做厚到 40 个（当前 10 个）

| 项 | 内容 | 成本 |
|---|---|---|
| 补 30 个 Skill | 每个约 200 行 JSON + 校验 + 实跑 | **30–45 小时**（我可以直接产出） |
| 分发接入 | 打包成 WorkBuddy skill（复用现有 40+ 分发通道） | **2 小时**（渠道已有，边际成本≈0） |
| 官网入口 | AI 导航页挂入口，吃 GEO 收录 | **1 小时**（站点已有） |
| 找真实用户 | 10 人 × 7 天陪跑 + 记录卡点 | **14 天**（唯一的真成本，不能省） |

**现金支出：≈ 0 元**（服务器都省了 —— 这是纯文件方案的红利）

### 阶段二：验证「不需要我也能运转」

| 项 | 成本 |
|---|---|
| 独立第三方实现协议 | **无法自己控制，取决于外部** |
| 自己的成功标准 | 看是否有陌生人提交了合规 Skill |

### 阶段三：**不建议现在做**

| 项 | 为什么现在不做 |
|---|---|
| 做 App / 智能体 | 主体 + 备案 + 服务器 + 数据合规，一个人扛不住 |
| 接 K12 | 双减 |
| 做收益分成 | 需对公账户（与拼豆项目同结论） |

### 你要付出的真实成本 = 时间 + 一个判断力要求

| 成本项 | 量化 |
|---|---|
| **决策成本** | 每 3 个月要决定「要不要收手」——这个比写代码难 |
| **持续内容成本** | 方法库要持续更新（这是唯一会腐烂的部分） |
| **诱惑成本** | 有人来谈「付费接入」时，要忍住不接 —— 破了原则整个项目就废了 |

**我必须诚实的一句话：**
> 纯协议方案的**现金成本接近 0，但放弃的收入也接近 0**。
> 如果你的最终目标是赚钱，OpenLMP 不是最短路径。
> 如果你的最终目标是「让这个东西不依赖我」，那它是唯一路径。

**这是你的选择，不是我的判断。**

## 七、如果你确实想要「AI 自动参与」——安全的做法

文心版里「让 AI 自动共建」的方向我认可，但**必须改成无幻觉版**：

| 文心版做法（❌） | 安全版做法（✅） |
|---|---|
| AI 爬教材自动生成 Skill | **AI 提议 → 人工/规则校验 → 才入库**。Skill 里已实现「checkpoint 客观性」「evidence 不得虚标」两道机器闸 |
| AI 三层审核「杜绝幻觉」 | 不说「杜绝」，说**「机器可校验的结构性约束」**。我们校验的是格式与可判定性，不是事实真伪 |
| AI 自动同步到豆包/扣子等平台 | **不做自动分发**。改为「Skill 公开，任何人可自行粘贴接入」。分发权不外授 |

**这条很重要**：一旦你去「自动同步到别人的 AI 平台」，你就是在给平台送流量、送数据、送控制权 —— 那和建中心没区别。

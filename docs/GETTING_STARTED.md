# 开始使用 · 我该怎么学？

> 这份文档是给**普通学习者**看的。
> 如果你只想「有样东西能拿来用」，看这一份就够；想改协议或贡献方法，再去看 `SPEC.md`。

---

## 一、这个东西到底是什么

OpenLMP 是一份**学习方法协议**。

简单说：它把「怎么学才有效」从一堆含糊的建议，变成了**可以一步步照做的动作清单**。

别的资料会告诉你：

> 「要多复习」「要理解为主」「要做笔记」

这些话都对，但**执行不了**——你不知道「复习几次」「理解到什么程度算理解」「笔记记成什么样」。

OpenLMP 的做法是，把每个方法拆成步骤，每一步配一条**能判定过没过的标准**。比如：

```
第 5 步：压成一句话（约 3 分钟）
做什么：把讲解稿压缩成一句话，必须包含因果关系。
验收线：产出恰好 1 句话，含「因为…所以…」结构，≤60 字
不通过就回到：第 2 步
```

这样就**不存在「学没学会」的模糊地带**——达标没达标，对照着看就知道了。

## 二、三步开始

### 第一步：找到适合你的方法

```bash
python assets/lmp.py list
```

会看到 50 个方法按 8 类分组列出，带**循证等级**。等级含义：

| 标识 | 含义 |
|---|---|
| `循证强` (high) | 有多项对照实验支持，优先选这些 |
| `循证中` (medium) | 有一些支持性证据，结论稳健性中等 |
| `经验` (anecdotal) | 主要来自实践经验总结，缺少严格实验验证 |

也可以用症状直接搜：

```bash
python assets/lmp.py recommend "读了三遍但讲不清"
python assets/lmp.py recommend "背了就忘"
python assets/lmp.py recommend "笔记记了从来不看"
```

### 第二步：打印执行剧本照着做

```bash
python assets/lmp.py run feynman --topic "为什么间隔重复有效"
```

会输出完整步骤：每一步做什么、产出什么、怎么算完成、不通过回到哪一步。

**照着做就行。**

### 第三步：记录结果，让它帮你排复习

```bash
python assets/lmp.py review          # 看看今天该复习哪些
python assets/lmp.py grade feynman 4 # 复习完给自己打个分（0-5）
```

打完分系统会按 SM-2 算法算出**下次该什么时候再复习**。打分规则：

| 分 | 含义 |
|---|---|
| 0 | 完全想不出 |
| 1 | 想了很久才出 |
| 2 | 提示后想起 |
| 3 | 基本想出 |
| 4 | 轻松想出 |
| 5 | 毫不费力 |

⚠️ 打 0-2 分会把间隔重置回 1 天——这是对的，说明还没真正记住。

## 三、常见困惑

**Q：50 个方法我都要学吗？**
不要。它们是**工具箱**，不是课程。按你当前的症状挑一个用，用完看效果再决定下一步。

**Q：循证等级是「经验」的方法是不是没用？**
不是。它表示**缺少严格实验验证**，不等于无效。番茄钟、卡片盒笔记这类都有大量人在用，只是很难做严格的对照实验。如实标注是为了让你知道**证据强度**，不是劝退。

**Q：数据存在哪？安全吗？**
存在你自己的电脑上，默认 `~/.local/share/openlmp/learner-state.json`。**不联网、不注册、不需要密钥**，没有任何东西会离开你的机器。可以用环境变量 `OPENLMP_STATE` 改位置。

**Q：我能改这些方法吗？**
能。全部 CC0 公共领域贡献——随便改、随便商用、不用署名。

**Q：为什么每步都要写「验收线」？**
因为「我懂了」是最容易骗自己的一句话。写不出可判定的标准，通常意味着这一步**其实没做扎实**。这是本协议最核心的一条纪律。

## 四、按症状速查

| 如果你…… | 优先试 |
|---|---|
| 读了很多遍但说不清 | `feynman`（费曼学习法） |
| 背了就忘 | `spaced-repetition`（间隔重复）、`active-recall`（主动回忆） |
| 分章节都会、综合就不会 | `interleaving`（交错练习） |
| 笔记记了从来不看 | `zettelkasten`（卡片盒）、`note-flow-code`（笔记流水线） |
| 做了很多题还是错 | `error-notebook`（错题本溯源） |
| 学完就忘、用不上 | `transfer-question`（迁移提问） |
| 坐不住、总走神 | `pomodoro-diagnose`（专注节奏诊断） |
| 定了计划总执行不了 | `if-then-planning`（执行意图）、`timeboxing`（时间盒） |
| 练了很久没长进 | `deliberate-practice`（刻意练习） |

完整清单见 `../references/ALL-SKILLS.md`。
